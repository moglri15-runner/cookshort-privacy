COOKSHORT

데이터 삭제 안내

앱: CookShort · 개발자 연락처: moglri15@gmail.com

1. 계정이 없습니다

CookShort는 회원가입·로그인 기능이 없습니다. 앱이 저장하는 데이터는 서버가 아니라 이용자의 기기 안에만 저장되며, 별도의 계정 데이터가 회사 서버에 존재하지 않습니다.

2. 삭제 방법

아래 방법으로 언제든 즉시 데이터를 삭제할 수 있습니다.

  1. 앱 삭제(제거): 기기에서 CookShort 앱을 삭제하면 저장된 모든 데이터가 함께 사라집니다.
  2. 앱 데이터만 지우기: 기기 설정 → 앱 → CookShort → 저장공간/데이터 → “데이터 삭제” 또는 “저장공간 지우기”를 누르면 앱은 유지한 채 저장된 데이터만 삭제됩니다.
  3. 직접 요청: 위 방법이 어려우신 경우 moglri15@gmail.com 으로 삭제를 요청해 주시면 확인 후 처리해 드립니다.

3. 삭제되는 데이터 종류 및 보관 기간

  • 북마크한 영상 목록 — 기기 내 저장, 위 방법으로 즉시 삭제. 서버 보관 없음.
  • 검색·재료 키워드, 추천 기록 — 기기 내 저장, 위 방법으로 즉시 삭제. 서버 보관 없음.
  • 검색어(YouTube 검색 요청) — 요청 처리 목적으로만 순간적으로 전달되며, 저희 쪽에서 별도로 보관하지 않습니다.
  • 광고 식별자(광고 ID) — Google AdMob이 처리합니다. 기기 설정의 “광고 ID 재설정”으로 직접 초기화할 수 있으며, Google의 보관·삭제 정책은 Google 개인정보처리방침을 따릅니다.

CookShort가 자체적으로 보관하는 서버 측 개인 데이터는 없으므로, 위 기기 내 데이터는 삭제 즉시 남는 사본 없이 제거됩니다.
